Project Identification & Abstract

PROJECT NAME
CyberFortify
PROJECT TYPE
BTech Final Year Cybersecurity Field Project
ARCHITECTURE
Red Team Simulator + Blue Team SIEM Evaluator
TARGET APPLICATION
Fortress Banking Portal (Isolated Mock Target)

Abstract: Modern cybersecurity relies heavily on intrusion detection systems (IDS) and security information and event management (SIEM) solutions. However, evaluating the efficacy, detection latency, and false-positive rates of these defenses in production is hazardous. CyberFortify establishes an automated, safe, and controlled testing environment where standardized adversary scenarios (authentication brute force, broken access control, SQL injection, and input validation/XSS) are executed against a dedicated local target application. Structured application audit logs are correlated through rule-based detection engines, and before-and-after retesting quantitatively evaluates defense remediations.

Mathematical Evaluation Framework

DETECTION RATE (RECALL / SENSITIVITY)
Recall = TP / (TP + FN) × 100%

Proportion of actual attack simulations that were correctly identified and alerted by the Blue Team.

PRECISION RATE
Precision = TP / (TP + FP) × 100%

Proportion of generated alerts that corresponded to real attacks rather than benign false alarms.

F1-SCORE (HARMONIC MEAN)
F1 = 2 × (Precision × Recall) / (Precision + Recall)

Balanced metric measuring overall detection effectiveness while penalizing missed detections and false alarms.

DETECTION LATENCY
Latency = Timestamp(Alert) - Timestamp(Event)

Time delay in milliseconds from request receipt to SIEM correlation and alert generation.

Blue Team Detection Rule Set

RULE_UNAUTHORIZED_ACCESS_01 Unauthorized Admin Access CRITICAL Broken Access Control Status 401/403 or unauthenticated requests to administrative endpoints
RULE_SQLI_DETECTED_01 SQL Injection Syntax Anomaly CRITICAL Injection Signature regex matching tautologies (' OR 1=1), UNION queries, comments
RULE_XSS_INPUT_01 Malicious Script & Tag Injection HIGH Cross-Site Scripting Inspection for <script>, event handlers (onerror=), SVG vectors
