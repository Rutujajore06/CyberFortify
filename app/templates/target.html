🔑 Customer & Staff Login

POST /api/target/login

Authenticate with mock banking credentials. When Rate Limiting is active, 3 consecutive failed attempts trigger account/IP lockout (HTTP 429).

🔍 Customer Directory Search

GET /api/target/search

Query banking customers by username. In vulnerable mode (defenses OFF), raw SQL concatenation permits SQL injection (' OR 1=1 --).

Enter a query or select a probe above to search target database records.

🏛️ Treasury Reserve Vault & Secrets

GET /api/target/admin/secrets

Protected administrative endpoint. In vulnerable mode (RBAC OFF), forced browsing exposes the vault master key without authentication!

Click above to execute an authorization check against the administrative vault endpoint.

💬 Customer Feedback & Inquiries

POST /api/target/feedback

Submit inquiries to Fortress Bank. In vulnerable mode (Sanitization OFF), unsanitized script tags (XSS) are stored directly into SQLite.
